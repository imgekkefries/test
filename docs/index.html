Check key & balance

POST /solutions/login

Validates your API key and returns the current account balance. Use it to confirm a key is still valid or to display how much credit is left before you start solving.

How to make a request

Send a JSON body containing only your API key.

POST http://localhost:5000/solutions/login
Content-Type: application/json

{
  "key": "YourApiKeyHere..."
}

Request fields

FieldTypeRequiredDescription
key string Yes Your account API key (45 characters).

Successful response

// HTTP 200
{
  "code":    200,
  "balance": 4.95       // current balance in EUR
}

If the account has an active timeout, an extra countdown field is included.

Responses you can expect

200 OK

The key is valid.

Fields: balance, optionally countdown
400 Bad request

No key was provided in the body.

Fields: error = missing key
401 Unauthorized

The key is malformed or does not belong to an existing account.

Fields: error = invalid key
429 Too many requests

Rate limit exceeded. /solutions/login allows 30 requests per minute.

Fields: none (rate-limit response)

Solve a CAPTCHA

POST /solutions/solve

Sends a CAPTCHA image and its prompt, and returns the actions needed to solve it. You are only charged when a solve succeeds.

Three AI modes exist and are all off by default - AlwaysUseAI, AIFallback, and ExperimentalAI. They can be toggled on the Preferences page. Both AI paths are billed at €0.002 per successful solve.

How to make a request

Send a JSON body with your API key, the prompt, and the image encoded as base64.

POST http://localhost:5000/solutions/solve
Content-Type: application/json

{
  "key":     "YourApiKeyHere...",
  "prompt":  "Drag the matching shape into the empty cell",
  "image":   "data:image/png;base64,iVBORw0KGgo...",
  "capture": { /* optional - required for ExperimentalAI (see below) */ }
}

Request fields

FieldTypeRequiredDescription
key string Yes Your account API key (45 characters). Obtained from /solutions/register or /solutions/login.
prompt string Yes The CAPTCHA instruction text, e.g. "Click the 3 items used for gaming or sports".
image string Yes The CAPTCHA image as a base64 string. A full data-URI prefix is accepted. The request body is capped at 15 MB.
capture object No Extra hCaptcha capture metadata. Required for the ExperimentalAI path - if missing, the request transparently falls back to the regular AI solver. See Experimental AI.

Successful response

// HTTP 200 - single-page result
{
  "code":    200,
  "actions": [ /* solver-specific action objects */ ],
  "time":    842,        // ms spent solving
  "price":   0.002,      // EUR charged (0.0 on free solvers)
  "balance": 4.95,       // your balance after the solve
  "ai":      false       // true when any AI path handled it
}

// HTTP 200 - multi-page result (ExperimentalAI only)
{
  "code":         200,
  "actions":      {
    "page1": [ /* actions for round 1 */ ],
    "page2": [ /* actions for round 2 */ ]
  },
  "time":         1420,
  "price":        0.002,
  "balance":      4.948,
  "ai":           true,
  "experimental": true   // present only on the ExperimentalAI path
}

actions is normally an array of action objects. Its exact shape depends on the solver that handled the prompt.

When the ExperimentalAI solver handles the request and the challenge has multiple rounds (which happens for grid, area-points, and multi-move drag challenges), actions becomes an object keyed "page1", "page2", … - one array per round. Single-round solves still return a plain array.

Responses you can expect

200 Solved

Returned when a solver produced actions.

Fields: actions, time, price, balance, ai
400 Bad request / Unsupported

Missing or malformed fields, a bad image, or no solver matched the prompt (and AI fallback is off).

Fields: error (missing key prompt or image, bad input, bad image, or unsupported), sometimes time
401 Unauthorized

The key is missing, malformed, or does not belong to an existing account.

Fields: error = invalid key
402 Not enough balance

The matched solver has a price and your balance is too low to cover it.

Fields: error = balance, price
422 Could not solve

The solver ran but returned no usable actions.

Fields: error (unsolved, ai_failed, or experimental_ai_failed), time, sometimes hint
429 Too many requests

Rate limit exceeded. /solutions/solve allows 60 requests per minute.

Fields: none (rate-limit response)
500 Server error

An unexpected error occurred on the server.

Fields: none
You are only charged when a solve succeeds. Unsupported prompts, failed solves, and balance errors never deduct from your balance.

Experimental AI

Experimental AI is an alternative solver optimised for hCaptcha-style puzzles. It is often faster than the regular AI path, but may occasionally fail. Both AI paths cost €0.002 per successful solve.

Enable it on the Preferences page by turning on Always Use AI (or AI Fallback) and selecting Experimental AI as the AI type.

The capture object

To use Experimental AI, add a capture object to your /solutions/solve body with the raw challenge data the browser captured. All fields below are forwarded to the upstream recognize-tl service, so supply every value you can scrape - missing ones reduce solve quality.

FieldTypeRequiredDescription
getcaptcha_b64 string Yes Base64 of the raw /getcaptcha response body. Forwarded as getcaptcha_b64.
hsw_b64 string Yes Base64 of hsw.js (must be at least 200 KB). Forwarded as hsw_b64 when present.
sitekey string Yes The hCaptcha sitekey (UUID in the /getcaptcha/<sitekey> URL). Forwarded inside client.sitekey.
hcaptcha_version string Yes Version string parsed from the challenge iframe URL. Forwarded inside client.hcaptcha_version.
widget string Yes One of "checkbox", "challenge", or "enclave". Forwarded inside client.widget.
locale string Yes Browser locale, e.g. "en-US". Forwarded inside client.locale.
timezone string Yes IANA timezone, e.g. "Europe/Amsterdam". Forwarded inside client.timezone.
width int Yes Challenge image width in pixels. Used locally to convert normalised coordinates into pixel clicks.
height int Yes Challenge image height in pixels. Used locally for coordinate conversion.
tile_rects array No Array of [idx, x, y, w, h] DOM rects for each grid tile. Required only for grid-style challenges with tiles; used locally to map tile indices to exact pixel centres. Without it, the solver falls back to guessing a uniform grid from total. Omit for non-tile challenges (drag, area, etc.).
width, height, and tile_rects are consumed locally by the ExperimentalAI solver - they are not forwarded to the upstream service. Everything else is sent verbatim in the outbound recognize-tl payload.

Example request

POST http://localhost:5000/solutions/solve
Content-Type: application/json

{
  "key":    "YourApiKeyHere...",
  "prompt": "accounts.hcaptcha.com/demo",
  "image":  "data:image/png;base64,iVBORw0KGgo...",
  "capture": {
    "getcaptcha_b64":   "eyJ0eXAiOiJKV1Qi...",
    "hsw_b64":          "Ly8gQ29weXJpZ2h0I...",
    "sitekey":          "a5f74b19-9e45-40e0-bd44-6c9e1c5d0a5c",
    "hcaptcha_version": "a6c3f4b",
    "widget":           "challenge",
    "locale":           "en-US",
    "timezone":         "Europe/Amsterdam",
    "width":            400,
    "height":           400,
    "tile_rects":       [[0, 24, 24, 116, 116], [1, 142, 24, 116, 116]]  // include only if grid challenge
  }
}

Multi-page results

Some challenges span more than one round. When that happens, actions is an object keyed by page instead of a flat array: 

{
  "actions": {
    "page1": [ ["click", [412, 338]] ],
    "page2": [ ["click", [120, 205]] ]
  }
}

For single-round challenges actions stays a plain array, exactly like the regular solvers.

If capture is missing or the solver returns nothing usable, the request transparently falls back to the regular AI solver (when Always Use AI is on).
